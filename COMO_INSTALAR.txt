THE WEEKLY FLYER STUDIO — PWA CON DIAGNÓSTICO

GitHub Pages:
1. En el repositorio habilita Settings > Pages > Build and deployment > Deploy from a branch > main / (root).
2. En la RAÍZ de esa rama (no dentro de una carpeta extra) deben estar:
   index.html, manifest.webmanifest, sw.js, icons/
3. Abre la dirección PUBLICADA https://USUARIO.github.io/REPOSITORIO/
   No abras github.com/USUARIO/REPOSITORIO.
4. Toca «Revisar instalación»; si falla algún icono o el manifest, revisa sus rutas.
5. Pulsa «Instalar en Android», o menú de Chrome ⋮ > Añadir a pantalla de inicio / Instalar aplicación.
6. Espera a que el sitio haya terminado de desplegar. Si acabas de sobrescribir archivos, recarga la página en Chrome.

Este ZIP no es APK. Chrome decide cuándo mostrar el aviso. La app no puede forzar un aviso que el navegador no autorice.
